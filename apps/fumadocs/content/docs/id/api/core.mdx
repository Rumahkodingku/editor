`@rumahkodingku/editor-core` tidak bergantung pada framework dan aman untuk diimpor
pada SSR. Hanya ekspor di bawah ini yang bersifat publik.

## Editor

| Ekspor | Jenis | Catatan |
| --- | --- | --- |
| `createEditor(options)` | fungsi | Membuat editor Tiptap dengan preset inti |
| `CreateEditorOptions` | tipe | Opsi untuk `createEditor` |
| `EDITOR_CORE_PACKAGE_NAME` | konstanta | Pengenal paket |

## Kesalahan

`EditorError`, `EditorConfigError`, `EditorContentError`,
`EditorSchemaVersionError`, dan `EditorUploadError` diekspor agar kegagalan dapat
dibedakan. Kesalahan mempertahankan `cause`-nya.

## Tipe Tiptap

Tiptap adalah bagian dari kontrak publik: `AnyExtension`, `Editor`, dan `JSONContent`
di-ekspor ulang dari `@tiptap/core`.
