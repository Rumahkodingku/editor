title: Core API
description: Public exports of @rumahkodingku/editor-core.
---

`@rumahkodingku/editor-core` is framework-independent and import-safe in SSR.
Only the exports below are public.

## Editor

| Export | Kind | Notes |
| --- | --- | --- |
| `createEditor(options)` | function | Creates a Tiptap editor with the core preset |
| `CreateEditorOptions` | type | Options for `createEditor` |
| `EDITOR_CORE_PACKAGE_NAME` | const | Package identifier |

## Errors

`EditorError`, `EditorConfigError`, `EditorContentError`,
`EditorSchemaVersionError`, and `EditorUploadError` are exported so failures can
be distinguished. Errors preserve their `cause`.

## Tiptap types

Tiptap is part of the public contract: `AnyExtension`, `Editor`, and `JSONContent`
are re-exported from `@tiptap/core`.
