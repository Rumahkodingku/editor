RumahKodingku Editor is a reusable, typed, composable **WYSIWYG rich text
editor** ecosystem for modern web applications. It is a TypeScript monorepo
built on **Tiptap + ProseMirror**, with **React** as the first supported UI
framework and a **framework-independent core** so additional adapters can be
added later without duplicating editor logic.

## Packages

- `@rumahkodingku/editor-core` — framework-independent editor logic: editor
  creation, the default extension preset, content utilities, JSON/HTML
  serialization, schema versioning, toolbar definitions, the upload contract,
  and labels.
- `@rumahkodingku/editor-react` — the React adapter: the `Editor` component,
  composable surfaces, controlled/uncontrolled behavior, the default toolbar,
  and the published stylesheet.
- `@rumahkodingku/editor-vue` — planned, not implemented.

## Key facts

| Area | Contract |
| --- | --- |
| Editor engine | Tiptap 3.x on ProseMirror |
| Canonical content | Tiptap/ProseMirror **JSON** |
| HTML | Output-only serialization |
| Persistence | `{ schemaVersion, content }` envelope |
| Framework | React 19 (peer dependency) |
| Runtime | Node `>=22` for build tooling |
| Styling | Framework-agnostic CSS with `--rk-editor-*` variables |
| Storage | Consumer-provided through `ImageUploadHandler` |
