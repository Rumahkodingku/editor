RumahKodingku Editor is a reusable, typed, composable WYSIWYG rich text editor
built on Tiptap and ProseMirror.

Full product documentation — installation, quick start, API reference, guides,
and examples — is built in Phase 08. Until then, the product and architecture
decisions live in the repository.

## Current Status

The repository is in **Phase 00 — Repository Foundation**. The editor packages
(`@rumahkodingku/editor-core` and `@rumahkodingku/editor-react`) are not
published yet.

## Repository Documents

- `PRD.md` — product requirements (what and why)
- `ARCHITECTURE.md` — architecture and constraints (how)
- `AGENTS.md` — operational rules for AI agents and contributors
- `docs/roadmap/` — implementation roadmap
