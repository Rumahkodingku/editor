First public release of RumahKodingku Editor.

- `@rumahkodingku/editor-core`: framework-independent core with editor creation,
  the default extension preset, content utilities, JSON/HTML serialization,
  persistence schema versioning, the image-upload contract, toolbar definitions,
  and labels.
- `@rumahkodingku/editor-react`: the React adapter with the `Editor` component,
  composable surfaces, controlled/uncontrolled content, editable/read-only/
  disabled states, the default toolbar, link/image controls, and the published
  stylesheet.
